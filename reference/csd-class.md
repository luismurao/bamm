# Class `csd`

Class `csd`

## Value

An object of class csd

## Slots

- `connections`:

  A data.frame with four columns: x, y, clusterID and cluster_size

- `interactive_map`:

  A leaflet map with markers showing the geographical clusters

- `raster_map`:

  A raster map with cluster IDs as values.

# Class `pam` Presence-Absence Matrix

Class `pam` Presence-Absence Matrix

## Value

An object of class pam

## Slots

- `pams`:

  A list of sparse matrices representing Presence-Absence Matrix for
  each simulation time

- `which_steps`:

  Simulation steps

- `sp_names`:

  Names of species in the PAM

- `grid`:

  Raster grid of the studied area

- `cellIDs`:

  Cells with ids of the PAM sites
